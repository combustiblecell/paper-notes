# 非对比自监督（VICReg）

来源：LeCun 2022 立场文 §4.3–4.5；VICReg 原论文 Bardes et al., 2021（arXiv:2105.04906）

## 一句话

训练 JEPA 时**不靠负样本把「不像的」拉开**，而是用正则项保证表征既有信息、又彼此不冗余、还能被预测。

## 自监督在这里做什么

不靠人工标签。给定观察到的 $x$ 和可能未观察到的 $y$（例如过去 vs 未来），学一个能量 $F(x,y)$：两者相容时能量低，不相容时能量高。

## 必须防的坑：塌缩（collapse）

如果只把「对的一对」能量压低，模型可能学会：

- 编码器输出常数（什么输入都一样）
- 或潜变量 $z$ 信息量太大，预测器直接抄 $z$、无视 $s_x$

结果是整片空间能量都很低，模型没有学到任何结构。

## 对比 vs 非对比

| | 对比方法 | 非对比（正则化）方法 |
|--|--|--|
| 做法 | 正样本能量↓，再造负样本 $\hat{y}$ 把能量↑ | 正样本能量↓，同时缩小「低能量区域」的体积 |
| 例子 | SimCLR、MoCo、InfoNCE、CPC | VICReg、Barlow Twins |
| LeCun 的批评 | 高维下负样本数量可能随维度指数增长 | 更有希望避开维数灾难 |

## VICReg 三条力

1. **Variance（方差）**：各维标准差不能掉到阈值以下 → 表征别变成常数
2. **Invariance / 预测误差**：$s_y$ 要能从 $s_x$ 预测出来（最简情况两路表征尽量相等）
3. **Covariance（协方差）**：不同维协方差推向 0 → 少冗余

另外：潜变量 $z$ 的信息量要小（离散 / 低维 / 稀疏 / 随机），防止「抄 $z$」式塌缩。

文中四条训练准则（Figure 13）：

1. $s_x$ 对 $x$ 信息量尽量大
2. $s_y$ 对 $y$ 信息量尽量大
3. $s_y$ 容易由 $s_x$ 预测
4. $z$ 信息量尽量小
