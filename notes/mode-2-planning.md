# Mode-2 规划

来源：LeCun 2022 立场文 §3.1，对应 Kahneman 的快/慢系统；实现上就是带学习模型的 MPC。

## 一句话

不是看见就动手，而是先在**世界模型里试一串动作**，看未来代价（能量）多少，再选总能量最低的那条，只执行第一步。

## Mode-1 vs Mode-2

| | Mode-1 | Mode-2 |
|--|--------|--------|
| 类比 | Kahneman System 1（快、直觉） | System 2（慢、思考） |
| 做法 | 策略网络直接 \(a = A(s)\) | 用世界模型展开未来，对动作做能量最小化 |
| 代价 | 一次前向，便宜 | 反复跑世界模型，贵 |
| 用途 | 已熟练的技能 | 新情境、需要推理/规划时 |

Mode-2 学会的最优动作可以**蒸馏**进 Mode-1，变成习惯（amortized inference）。

## Mode-2 步骤

1. 感知当前状态 \(s[0]\)
2. actor 提出动作序列 \(a[0],\ldots,a[T]\)
3. 世界模型递推 \(s[t+1] = \mathrm{Pred}(s[t], a[t])\)
4. cost 把各步能量加起来 \(F = \sum_t C(s[t])\)
5. 用梯度或搜索改动作，直到总能量变低
6. 只把第一个（或前几个）动作发给执行器，下一拍重新感知

这就是 **MPC（模型预测控制）+ receding horizon**。和经典最优控制的差别：世界模型和代价函数都是学出来的。

## 「规划」在这里的含义

不是写逻辑规则，而是：**在可微世界模型里做能量最小化 / 约束满足**。

层次化时：高层先规划「去火车站」，作为低层子目标；低层再规划「怎么开门、怎么开车」。

## 和行为主义 RL 的差别

Mode-2 尽量少在真实世界试错。奖励/内在代价是可微的，梯度可以穿过世界模型流回动作，而不必靠海量真实交互估策略梯度。
