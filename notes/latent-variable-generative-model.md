# 潜变量生成模型

来源：Yann LeCun, *A Path Towards Autonomous Machine Intelligence* (2022) §4.2–4.4、Figure 10(b)  
https://openreview.net/forum?id=BZ5a1r-kVsf

## 一句话

用一个**没被直接观察到、需要推断的变量 $`z`$**，去参数化「给定 $`x`$ 之后，有哪些 $`y`$ 说得通」；生成式版本会真的画出 $`\tilde{y}`$，而不是只预测表征。

## 潜变量是干什么的

潜变量 $`z`$：**输入里没有、但推断时要补上的信息**。它参数化 $`x`$ 与一簇相容 $`y`$ 之间的关系，装着「关于 $`y`$、却无法从 $`x`$ 读出」的那部分。

例子（§4.2）：

- 同一场景两张照片：$`z`$ 可以是相机位移
- 车开到岔路口：$`z`$ 可以是「左转还是右转」
- 预测未来：$`z`$ 是过去无法决定的部分（前车加速还是刹车）

能量模型里写成 $`E_w(x,y,z)`$。见到一对 $`(x,y)`$ 时，先找使能量最低的 $`z`$：

```math
\check{z} = \arg\min_{z \in Z} E_w(x,y,z),\quad
F_w(x,y) = E_w(x,y,\check{z})
```

LeCun 把 $`F_w`$ 称为零温度自由能，但仍叫它能量。EBM **不必**是概率模型。

## 生成式这一支（Figure 10(b)）

**确定性生成 / 回归**（Figure 10(a)）：给定 $`x`$ 只吐一个 $`\tilde{y}`$。能量在 $`y=\tilde{y}`$ 为零，别处更高。**不会塌缩**。

**潜变量生成模型**（非确定性生成，Figure 10(b)）：$`z`$ 在集合 $`Z`$ 上变动时，预测 $`\tilde{y}`$ 扫出一块 $`\mathrm{Pred}(s_x, Z)`$。这块应该刚好覆盖「和 $`x`$ 相容的那些 $`y`$」。

文中例子：GAN、VAE、VQ-VAE 用于视频预测，就是这类思路——用潜变量表示多模态输出、减轻模糊。它们**会生成 $`y`$**（像素级下一帧等）。

## 主要限制

1. **容量过大就会塌缩**：若 $`z`$ 维度 ≥ $`y`$，系统可以给整个 $`y`$ 空间零能量。限制 $`z`$ 的信息量（离散 $`k`$ 值最多 $`k`$ 个零能量点；$`Z`$ 是 $`d`$ 维流形则低能量区最多 $`d`$ 维）。
2. **丢不掉无关细节**：生成式潜变量模型没有对 $`y`$ 的抽象/不变表征，无关细节只能塞进 $`z`$，不能像 JEPA 编码器那样直接丢掉。  
   原文：“generative latent-variable models are not capable of eliminating irrelevant details, other than by pushing them into a latent variable… This is why we advocate against the use of generative architectures.”（第30页，§4.6）
3. **视频长期像素预测几乎不可能准**（树叶、水波等）。

## 和相邻概念的对比

| | 潜变量生成模型 | JEPA |
|--|----------------|------|
| 预测对象 | 直接生成 $`y`$（像素/信号） | 只预测表征 $`s_y`$ |
| 多模态 | 靠 $`z`$ 扫出一簇 $`\tilde{y}`$ | 编码器不变性 + 预测器里的 $`z`$ |
| 无关细节 | 只能推进 $`z`$ | 编码器可以丢掉 |
| 塌缩 | $`z`$ 信息量太大时会 | 用 VICReg 等非对比正则 + 限制 $`z`$ |

JEPA 被写成：联合嵌入架构 **加上** 潜变量生成架构的预测器，但**不生成 $`y`$**，只生成 $`s_y`$。
